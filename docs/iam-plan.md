# Sew4U Academy IAM Plan

## Purpose

This document defines the Identity and Access Management (IAM) structure for the simulated Sew4U Academy environment.

The goal is to provide employees, contractors, and volunteers with access based on their job responsibilities while following the principles of least privilege and role-based access control.

## Identity Lifecycle

User accounts will be managed through the following stages:

- New employee onboarding
- Account creation
- Department and group assignment
- Role-based access assignment
- Password and security policy enforcement
- Department or role changes
- Access reviews
- Employee termination
- Account disabling and deprovisioning

## Planned Security Groups

- Executive
- Human Resources
- Finance
- Programs
- Sewing and Creative Arts
- Wellness
- Operations
- IT
- Marketing
- Volunteers
- Contractors

## Security Principles

The Sew4U Academy environment will use:

- Least privilege
- Role-Based Access Control (RBAC)
- Strong password policies
- Account lockout policies
- Group-based permissions
- Separation of duties
- Administrative account protection
- Regular access reviews

## Planned IAM Scenarios

- Create a new employee account
- Assign users to departments
- Add users to security groups
- Grant access to department resources
- Remove unauthorized access
- Transfer an employee between departments
- Reset passwords
- Unlock locked accounts
- Disable terminated employee accounts
- Audit user and group permissions
- Investigate excessive privileges
- Test least-privilege access

## Status

Planning complete. Implementation will begin after the Windows Server and Active Directory environment is built.
