# Home Lab Architecture

## Purpose

This home lab simulates a small business IT environment where I can practice cybersecurity and system administration skills in a controlled environment.

## Virtualization Platform

- Oracle VirtualBox

## Systems

### Ubuntu Linux
- Operating System: Ubuntu Desktop
- Purpose: Linux administration, command-line practice, networking, security, and troubleshooting
- Status: Installation in progress

### Windows Server
- Purpose: Active Directory Domain Services, user and group management, permissions, Group Policy, and IAM practice
- Status: Planned

### Windows Client
- Purpose: Domain-joined workstation for practicing authentication, permissions, security policies, and troubleshooting
- Status: Planned

## Skills Practiced
